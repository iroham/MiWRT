Updating an installed firmware


An update keeps your settings. Packages you installed yourself are installed again after the update, this time for the kernel of the new version. The router does it by itself, but it needs internet for that.

Before the update

1. Save your settings. Open System, Backup / Flash Firmware and press "Generate archive". The file stays on your computer.

2. If you installed your own packages, save their list. This command prints it.

cat /etc/apk/world

The list holds the firmware's own packages too, yours are among them. Copy it somewhere. Usually the packages come back by themselves, but if one is missing from the new feed you will know what to install by hand.

3. Check that the internet works. The update takes a few minutes and the network is down meanwhile.

From the web interface

The easiest way is the System, Build update page. It checks GitHub for a newer version and shows what is new in it. With one button it downloads the image, checks the checksum and the release signature, and updates the router keeping the settings.

The router tells you about a new version by itself. Once a day it checks GitHub, and when a newer version is out, a button appears in the top bar and a block with the new version on Status, Overview. The check can be turned off on the Build update page.

From the console

miwrt-update check
miwrt-update apply

The first command asks GitHub whether a newer version is out. The second downloads it, checks it and installs it keeping the settings.

By hand

Download openwrt-qualcommbe-ipq95xx-xiaomi_be7000-squashfs-sysupgrade.bin from the release and update the router with the commands below. If your router has a different address, use yours.

scp -O openwrt-qualcommbe-ipq95xx-xiaomi_be7000-squashfs-sysupgrade.bin root@192.168.1.1:/tmp/
ssh root@192.168.1.1 "sysupgrade -v /tmp/openwrt-qualcommbe-ipq95xx-xiaomi_be7000-squashfs-sysupgrade.bin"

The update is written into the slot the router booted from. The factory firmware in the other slot is not touched. Settings, packages and enabled services move over by themselves.

What happens on the first boot

The first boot takes longer than usual, up to a couple of minutes. Do not cut the power until the LED is solid white.

If your settings live on a USB disk, the router reboots once by itself. That is expected.

Once the internet is up, the router installs your packages. You can watch it in Status, System Log, in the lines with be7000-romsync. If a package is missing from the new feed, it is skipped and the rest are installed. The skipped ones are listed in the line "not in the feed of this image, dropped".

The 5 GHz mode stays as it was.

Stock settings are not imported on an update. That only happens on the first install from stock, your settings stay as they were.

What to check afterwards

Status, Overview should show the version you installed and working internet.
Network, Wireless should show both networks. With country code RU there will be a warning that Wi-Fi 7 is off. The button next to it sets US for 5 GHz and Wi-Fi 7 works again.
System, Software should list your packages again. If something is missing, check your list and install it by hand.

If something goes wrong

Open Status, System Log and attach it to an issue at https://github.com/iroham/MiWRT/issues.

You can go back to the previous version the same way, with sysupgrade.bin from its release. If settings behave oddly after that, restore the archive you saved before the update.

The Slots page does not help here. The other slot holds the factory firmware, not the previous MiWRT version.
