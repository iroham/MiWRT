升级已安装的固件


升级会保留设置。你自己安装的软件包会在升级后重新安装一次，这次是为新版本的内核安装的。路由器会自动完成，但需要能上网。

升级之前

1. 保存设置。打开 系统, 备份与更新，点击"生成备份"。文件会保存在你的电脑上。

2. 如果你自己装过软件包，把软件包列表保存下来。下面这条命令会把列表打印出来。

cat /etc/apk/world

列表里也有固件自带的软件包，你装的那些也在其中。把它复制到别的地方保存。一般软件包会自己装回来，但如果新的软件源里缺了某个包，你就知道要手动装哪个。

3. 确认网络正常。升级需要几分钟，这段时间网络会断开。

通过网页界面

最简单的方法是用 系统, 固件更新 页面。它会在 GitHub 上检查有没有新版本，并显示新版本的更新内容。点一个按钮，它就会下载镜像、检查校验值和发布签名，然后升级路由器并保留设置。

有新版本时路由器会自己提示。它每天检查一次 GitHub，有更新的版本时，顶部栏会出现一个按钮，状态, 概览 页面会出现新版本的提示块。这项检查可以在 固件更新 页面关闭。

在命令行里

miwrt-update check
miwrt-update apply

第一条命令向 GitHub 查询有没有新版本。第二条命令下载新版本、检查，然后安装并保留设置。

手动升级

从发布页下载 openwrt-qualcommbe-ipq95xx-xiaomi_be7000-squashfs-sysupgrade.bin，然后用下面的命令升级路由器。如果你的路由器地址不同，换成你自己的地址。

scp -O openwrt-qualcommbe-ipq95xx-xiaomi_be7000-squashfs-sysupgrade.bin root@192.168.1.1:/tmp/
ssh root@192.168.1.1 "sysupgrade -v /tmp/openwrt-qualcommbe-ipq95xx-xiaomi_be7000-squashfs-sysupgrade.bin"

升级会写入路由器当前启动的槽位。另一个槽位里的原厂固件不受影响。设置、软件包和已启用的服务都会自动保留下来。

第一次启动时会发生什么

第一次启动比平时慢，最多要几分钟。在指示灯变成白色常亮之前不要断电。

如果你的设置放在 USB 硬盘上，路由器会自己重启一次。这是正常的。

网络连上以后，路由器会安装你的软件包。可以在 状态, 系统日志 里查看，看带有 be7000-romsync 的那几行。如果新的软件源里没有某个包，它会被跳过，其他的照常安装。被跳过的包会列在 "not in the feed of this image, dropped" 这一行里。

5 GHz 模式保持原样。

升级时不会导入原厂设置。只有第一次从原厂固件安装时才会导入，你现有的设置保持不变。

升级后检查什么

状态, 概览 应该显示你安装的版本，并且网络正常。
网络, 无线 应该显示两个网络。如果国家代码是 RU，会有一条 Wi-Fi 7 已关闭的提示。点旁边的按钮，5 GHz 会改成 US，Wi-Fi 7 就又能用了。
系统, 软件包 里应该又能看到你的软件包。如果缺了什么，对照你保存的列表手动安装。

如果出了问题

打开 状态, 系统日志，把日志附在 https://github.com/iroham/MiWRT/issues 的 issue 里。

也可以用同样的方法回到之前的版本，使用那个版本发布页里的 sysupgrade.bin。如果之后设置表现异常，就恢复升级前保存的备份文件。

槽位 页面在这里帮不上忙。另一个槽位里是原厂固件，不是之前版本的 MiWRT。
