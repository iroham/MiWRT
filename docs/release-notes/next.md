# After 2.2.0

Notes for the release after 2.2.0 collect here. Before the tag the file is renamed to `v<version>.md`; the build takes the release text from `docs/release-notes/<tag>.md`.

## In this release

- BE7000: **the build checks the firmware image against the size of its slot.** The slot is 40 MiB of flash: 296 blocks of 124 KiB for the kernel, the system and the in-slot settings volume. The limit written in the image recipe was never compared with anything, so an image that outgrew the slot would have been noticed by the router, while it writes the update. Now the build refuses an image that would leave the in-slot settings volume less than 25 blocks (3 MiB). With the settings on the data partition (the default) that volume only holds the pointer to them; it is the whole settings space of a router that keeps `bigoverlay` off.
- BE7000: **the system is compressed in 1 MiB blocks** instead of 256 KiB, which makes the image about half a megabyte smaller.
- BE7000: **`tcpdump-mini` and `iperf3` are no longer in the image**, and `ethtool-full` gave way to the plain `ethtool`. `apk add tcpdump-mini iperf3` brings the first two back; the feed has `tcpdump` and `ethtool-full` as well.
- Both routers: **Xray-core 26.11.9 in the package feed** as `miwrt-xray` (BE7000: `miwrt-xray-xz`, kept compressed on flash and unpacked into memory when it runs). On a processor without AES instructions, such as the Redmi AC2100's, its Chrome-like TLS hellos offer ChaCha20 before AES-GCM, as Chrome does there: a tunnel on the AC2100 runs at more than twice the speed. The VPN pages below install it when it is first needed.
- Redmi AC2100: **a MiWRT package feed of its own**, signed with the MiWRT key and listed in `/etc/apk/repositories.d/miwrt.list`, next to OpenWrt's feeds.
- Both routers: **VPN (Xray)** in the web interface (VPN, VPN (Xray)) and in the app. The router connects to a VPN server given as a `vless://` (REALITY included), `vmess://`, `trojan://`, `ss://` or `hysteria2://` link or a subscription, and sends the traffic of all devices, the chosen ones or all but the chosen ones through it. Servers can be tested; the page shows the address websites see, the delay and the current rate. The country's own websites can stay direct, name lookups go through the VPN, the guest and IoT networks never use it, and IPv6 is off for the devices that do. A pause, a schedule or approval of new devices holds for devices on the VPN too, and while the VPN restarts or cannot start, its devices wait instead of going out directly. Xray is installed on the first use and can be removed again.
- Both routers: **router link** (VPN, Router link; Router link in the app). Two MiWRT routers join over VLESS with REALITY: one is the exit, the other uses its internet, and either may open its home network to the other. They meet at the exit router when it has a public address, or at a server you rent; the page gives that server's Xray settings and a `docker run` line. Neither router can be reached through the link itself, and a changed code from the exit is taken without setting the link up again.
- Both routers: **Tailscale** (VPN, Tailscale; Tailscale in the app): sign in with a link or an auth key, subnet routes, exit node (offer and use), and the way to Tailscale's servers through the VPN. BE7000: a slim build of Tailscale 1.104.1 is in the image, switched off until you switch it on; the feed's full `tailscale` package stays available. Redmi AC2100: not in the image; the page installs it from the MiWRT feed, with compressed swap in memory, and removes it again.
- Redmi AC2100: **`kmod-nft-tproxy` is in the image** for the VPN; the MiWRT feed of this router now also carries `miwrt-tailscale`.
