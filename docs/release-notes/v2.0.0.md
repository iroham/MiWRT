# MiWRT 2.0.0

MiWRT now has its own home at github.com/iroham/MiWRT, and this is its first release there. The firmware underneath is the same as 1.5.4.1 (OpenWrt main d958caf, Linux 6.18.52, the same Wi-Fi drivers), with the fixes and changes below.

## Fixed

- **A clean install from the factory firmware works.** Right after flashing the factory image the settings volume is still blank; the factory-reset check took the failed look at it for a fault and restarted the router, which then went back to the factory firmware. A blank volume now simply means there is no reset waiting, and the boot carries on. A volume that was written but cannot be read still stops the boot as before.
- **Factory reset starts.** Reset from LuCI or the button showed "Erasing…" forever when the settings live on the joined volume, a USB disk or the spare slot: the reset job needed a random token from a tool (`od`) that is not in the image. The token now comes from `md5sum`, which is.

## Changed

- **A new web interface.** The MiWRT theme replaces Nimbus: a sidebar menu (a drawer on phones), light and dark modes, a search over every page with Ctrl+K or `/`, breadcrumbs, Save & Apply that stays in view on long pages, clearer buttons, switches and tables, and a picture of your router (BE7000 or Redmi AC2100) on the sign-in page. Everything can be reached from the keyboard and is labelled for screen readers. Routers on Nimbus switch over by themselves on the update.
- The SSH banner and System, Credits show the MiWRT logo, and the banner names the router it runs on.
- New address: updates, the package feeds and the update mirror now come from github.com/iroham/MiWRT and iroham.github.io/MiWRT. Routers on 1.x need the one-time step in the README (Coming from MiWRT 1.x).
- No longer built: the Add-ons page, Hybrid Failover, Zapret Manager with its steer feed, roamd and the USB modem page. Packages already installed stay, but get no updates from MiWRT. zapret, zapret2, ByeDPI, NetShift and AmneziaWG remain in the feed (System, Software).
- System, Credits lists the projects and people MiWRT is made from, OpenWrt first.
- Energy-Efficient Ethernet: checked on a running router, all four QCA8084 ports advertise no EEE to the other side, as intended. Nothing to change.

Install over MiWRT 1.x from System, Backup / Flash firmware with the `sysupgrade.bin`, keeping settings, or follow the install text in the archive for a router on the factory firmware.
