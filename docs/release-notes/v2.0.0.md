# MiWRT 2.0.0

The first release of MiWRT from github.com/iroham/MiWRT: OpenWrt for the Xiaomi BE7000 on OpenWrt main d958caf with Linux 6.18.52.

## In this release

- **Its own web interface.** A sidebar menu (a drawer on phones), light and dark modes, a search over every page with Ctrl+K or `/`, breadcrumbs, Save & Apply that stays in view on long pages, clearer buttons, switches and tables, and a picture of your router (BE7000 or Redmi AC2100) on the sign-in page. Everything can be reached from the keyboard and is labelled for screen readers.
- **Clean installs from the factory firmware.** The first boot after flashing the factory image treats the still blank settings volume as what it is and carries on. A volume that was written but cannot be read still stops the boot.
- **Factory reset** works wherever the settings live: the joined volume, a USB disk or the spare slot.
- **Updates** come from this repository: System, Build update checks once a day, downloads from GitHub Pages first, and accepts only release files signed with the key in the router's own image.
- **Packages:** a signed feed built from the same tree, kernel modules included. zapret, zapret2, ByeDPI, NetShift and AmneziaWG are in it (System, Software).
- The SSH banner and System, Credits show the MiWRT logo, and the banner names the router it runs on. System, Credits lists the projects and people MiWRT is made from, OpenWrt first.
- Energy-Efficient Ethernet stays off on all four QCA8084 ports, checked on a running router.

## Installing

On the factory firmware, follow the install text in the archive (`instruction-en.txt`, then `1-install-en.txt`). From another OpenWrt build that kept the factory bootloader, use `install-from-openwrt.sh` from the archive.
