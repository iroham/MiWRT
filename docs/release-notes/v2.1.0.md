# MiWRT 2.1.0

The first release from this repository: OpenWrt firmware for the Xiaomi BE7000 with a setup assistant for new installs, AdGuard Home on the router itself, and the service the MiWRT phone app talks to. What the firmware does as a whole is in the [README](https://github.com/iroham/MiWRT#readme).

## In this release

- **Setup assistant.** A router set up from scratch opens a step-by-step assistant in the web interface: language and region, how the router connects (main router with DHCP, a fixed address or PPPoE with VLAN, or an access point), Wi-Fi with a password generator and strength meter, guest Wi-Fi, a separate smart-home network, ad blocking, the router password, and a review page. Nothing changes until the last step; then everything is checked and applied in one go. The last page has QR codes for the MiWRT app and for joining the new Wi-Fi. English, Russian and Chinese. Routers updated with their settings kept never see it.
- **A safe way back.** The settings are saved before they are changed. An access point that gets no address from the main router within two minutes puts the old settings back, stays reachable at its old address and opens the assistant again, also when the power was cut in between.
- **The sign-in page** of a new router says to leave the password empty the first time.
- **AdGuard Home on the router.** Install it from the setup assistant or the app's Protection tab: it answers DNS for every network of the router, dnsmasq keeps addresses and local names, and its own page is at port 3000 (user `admin`, with a password of its own that you choose). If it stops and does not come back, DNS returns to the router by itself and an alert says so. An AdGuard Home elsewhere on the network can still be linked instead. Removing it, from the app or by hand, gives DNS back to the router at once.
- **App API:** `POST /v1/protection/install` and `/v1/protection/remove`; `GET /v1/protection` says where the ad blocker runs and whether the router can run one.

## Good to know

- AdGuard Home on the router needs 400 MB of memory and 32 MB free for settings and packages. A freshly installed BE7000 has about 19 MB free, so the assistant offers it only after the spare slot was joined (System, Slots) or the settings were moved to a USB disk; install it from the app's Protection tab afterwards.
- Remove AdGuard Home from the router before going back to a firmware older than 2.1.0: older versions do not know that DNS was handed to it.
- Ad blocking off for a single device matches the device by its IPv4 address.
- The image for the Redmi AC2100 is in this release too, under the same version: the files with `ac2100` in the name, with `sha256sums-ac2100.txt` as their checksum list. It is in testing and has not been flashed on a real router by the project yet; read `1-install-en.txt` in `miwrt-ac2100-v2.1.0.zip` first. It gets the setup assistant too; an AdGuard Home can only be linked there, the router has too little memory to run one.

## Installing

On the factory firmware, follow the install text in the archive (`instruction-en.txt`, then `1-install-en.txt`). From another OpenWrt build that kept the factory bootloader, use `install-from-openwrt.sh` from the archive. A router that already runs MiWRT updates on System, Build update, or with the `…-sysupgrade.bin` from this release; settings are kept.

Check the download against `sha256sums.txt`; the file is signed with the key every MiWRT image carries.
