# MiWRT 2.1.0

A setup assistant for new installs, and AdGuard Home on the router itself.

## In this release

- **Setup assistant.** A router set up from scratch opens a step-by-step assistant in the web interface: language and region, how the router connects (main router with DHCP, a fixed address or PPPoE with VLAN, or an access point), Wi-Fi with a password generator and strength meter, guest Wi-Fi, a separate smart-home network, ad blocking, the router password, and a review page. Everything is applied in one go; the last page has QR codes for the MiWRT app and for joining the new Wi-Fi. English, Russian and Chinese. Routers updated with their settings kept never see it. An access point that gets no address from the main router puts the old settings back and stays reachable.
- **The sign-in page** of a new router says to leave the password empty the first time.
- **AdGuard Home on the router.** Install it from the setup assistant or the app's Protection tab: it answers DNS for every network of the router, dnsmasq keeps addresses and local names, and its own page is at port 3000 (user admin). It needs 400 MB of memory and 32 MB free for settings (join the spare slot under System, Slots). An AdGuard Home elsewhere on the network can still be linked instead. Removing it, from the app or by hand, gives DNS back to the router at once.
- **App API:** `POST /v1/protection/install` and `/v1/protection/remove`; `GET /v1/protection` says where the ad blocker runs and whether the router can run one.
- The Redmi AC2100 image gets the setup assistant too (AdGuard Home can only be linked there: the router has too little memory to run it).

## Installing

On the factory firmware, follow the install text in the archive (`instruction-en.txt`, then `1-install-en.txt`). From another OpenWrt build that kept the factory bootloader, use `install-from-openwrt.sh` from the archive. From MiWRT 2.0.0, use System, Build update.
